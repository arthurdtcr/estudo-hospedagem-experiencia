Story de divulgação: 1080 × 1920, uma frase, um botão, com as zonas da interface respeitadas.

- **Use quando:** é para levar a um post novo, ao link ou à DM.
- **Você fornece:** rótulo, a frase em `capa` (para divulgar um post, repita a capa dele), um `lead` e a ação do botão.
- **Estrutura:** `ie-arte ie-story ie-grao ie-brilho`: a área útil já desconta `story-topo` (250px) e `story-base` (340px).
- **Não faça:** exportar com as `ie-guia` vermelhas: elas só existem para montar.
