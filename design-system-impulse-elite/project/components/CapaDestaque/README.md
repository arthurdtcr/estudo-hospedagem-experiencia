Capa dos destaques do perfil: inicial em serifa itálica `dourado` dentro de um anel `ouro-escuro`, sobre `preto-impulse`.

- **Use quando:** cria ou troca um destaque.
- **Você fornece:** a inicial do nome do destaque (uma letra).
- **Estrutura para exportar:** `<div class="ie-arte ie-quadrado"><div class="ie-destaque"><span>D</span></div></div>`: 1080 × 1080, o círculo ocupa a arte inteira e a letra e o anel se ajustam sozinhos. O Instagram recorta o centro. As miniaturas de 300px da prévia mostram como fica no perfil.
- **Não faça:** palavra inteira ou ícone no círculo: o nome aparece embaixo, pelo próprio Instagram.
