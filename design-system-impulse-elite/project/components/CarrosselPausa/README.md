Pausa: slide no tema Marfim que quebra o ritmo escuro e faz o leitor parar.

- **Use quando:** as três condições valem: a capa é escura (não C4, C6); a publicação anterior não teve Pausa (veja o registro); o carrossel tem 8 slides ou mais.
- **Você fornece:** três frases curtas, uma por linha, ou uma frase só, centralizada.
- **Estrutura:** `data-theme="marfim"` na `ie-arte` > `ie-area ie-centro`. `fundo`, `tinta` e `destaque` trocam sozinhos (o destaque vira `bronze`).
- **Âncora:** centro.
- **Não faça:** mais de uma por carrossel; grão, brilho ou diagonal.
