Checklist: itens com caixas retas para o leitor conferir. É o slide que as pessoas salvam.

- **Use quando:** o conteúdo é "confira se..." e o leitor vai voltar a ele (antes de anunciar, antes de contratar).
- **Você fornece:** um título curto com `<em>` e de 3 a 6 itens em `item ie-serif`, cada um uma frase afirmativa com ponto final, até 7 palavras.
- **Estrutura:** `ie-area ie-centro` > `titulo` + `<ul class="ie-checklist">` com um `<li><span class="item ie-serif">…</span></li>` por item. A caixa vem do CSS.
- **Não faça:** marcar as caixas (quem marca é o leitor); misturar com `CarrosselLista` no mesmo carrossel; pedir "salve" aqui (o pedido mora no fechamento).
