Slide interno padrão: rótulo no topo, bloco de texto na metade de baixo.

- **Use quando:** o slide explica uma ideia com manchete e apoio.
- **Você fornece:** rótulo (opcional, 2 ou 3 palavras), manchete, lead e corpo. Até 40 palavras no slide inteiro; se passar, divida em dois.
- **Estrutura:** `ie-arte ie-grao` > `ie-area ie-entre` > rótulo + bloco (manchete, lead, filete, corpo). Sem rótulo, troque `ie-entre` por `ie-centro` ou ancore o bloco no topo, para variar a âncora.
- **Cor do corpo:** `tinta-suave` quando é apoio; `tinta` quando é a conclusão do slide.
