Capa C4 · Dividida: pergunta em cima, no marfim, resposta embaixo, no preto. O corte diagonal entre as duas é o chanfro do monograma.

- **Use quando:** o título é pergunta e resposta, objeção e virada, ou "isso / mas aquilo". É a capa clara padrão quando a janela de três da grade pede uma.
- **Você fornece:** a primeira metade em `manchete` (uma linha, no máximo duas) e a segunda em `capa`, com o `<em>`.
- **Estrutura:** `ie-dividida-topo` com `data-theme="marfim"` e `ie-dividida-base` (com o `ie-arraste`) dentro de `ie-arte ie-grao`.
- **Conta como capa clara.** O carrossel não leva Pausa; o único outro marfim permitido é o `FechamentoEspelho` desta capa.
