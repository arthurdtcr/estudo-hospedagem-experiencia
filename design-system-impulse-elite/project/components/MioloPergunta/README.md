Pergunta: a dúvida que o leitor está tendo, num bloco em `superficie-alta` no topo, e a resposta logo abaixo do corte do chanfro.

- **Use quando:** o argumento precisa responder uma objeção no meio do carrossel ("E se o anúncio estiver bom?"). Quebra o preto contínuo sem gastar o marfim.
- **Você fornece:** um `rotulo-forte` curto ("Você deve estar pensando"), a pergunta em `manchete` (até 2 linhas), a resposta em `titulo` com `<em>` e até 25 palavras de `corpo`.
- **Estrutura:** `ie-arte ie-grao` > `ie-pergunta-topo` (rótulo forte + pergunta) + `ie-pergunta-base` (resposta + corpo).
- **Âncora:** topo.
- **Não faça:** usar como capa (a capa clara de pergunta é a C4); duas perguntas seguidas; rótulo comum além do rótulo forte.
