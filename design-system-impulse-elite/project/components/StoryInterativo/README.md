Story interativo: uma pergunta e um espaço reservado para o sticker do Instagram (enquete, caixinha de pergunta, quiz ou link).

- **Use quando:** o objetivo é conversa: descobrir dúvidas para os próximos posts ou abrir DM.
- **Você fornece:** um rótulo, a pergunta em `manchete` (até 10 palavras, um `<em>`) e o tipo de sticker.
- **Estrutura:** `ie-arte ie-story ie-grao` > `ie-area ie-centro` > rótulo + manchete + `ie-guia-sticker` (só para montar: o sticker real é colocado no app, sobre esse espaço).
- **Não faça:** desenhar o sticker na arte (ele não fica clicável); sticker dentro das zonas da interface.
