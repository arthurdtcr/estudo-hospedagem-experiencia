Capa C5 · Moldura: frase centralizada dentro de um fio dourado com o chanfro no canto, como uma placa.

- **Use quando:** a frase é uma afirmação curta e forte. É a capa mais sóbria: venha depois de uma capa clara ou barulhenta.
- **Você fornece:** a frase (até 4 linhas a 150px), um `<em>`.
- **Estrutura:** `<div class="ie-moldura"><div></div></div>` antes de `ie-area ie-centro ie-centrado` (z-index 2), com o `ie-arraste` centralizado embaixo da frase.
- **Não faça:** diagonal ou brilho (a moldura já ocupa a borda).
